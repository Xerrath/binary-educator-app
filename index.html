About Binary Educator

Learn what is happening behind the screen.

Computers represent information using binary values. At the most basic level, each binary digit is either a 0 or a 1. These binary digits are called bits.

Binary Educator breaks those ideas into interactive activities so you can see how powers of 2 create numbers and how groups of eight bits can represent ASCII characters.
